# サンプルCSV

[← 仕様書に戻る](../specification.md)

`1234.csv` は、実際の発注データではなく、[CSVファイル仕様](../docs/csv-format.md)に基づいて作成した**架空データ**のサンプルです。取引先名・商品名・JANコード・価格はすべて架空のものです。

## 内容

- 仕入先: 架空フーズ株式会社（架空）
- 伝票2枚（伝票番号 100001, 100002）、それぞれ末尾に合計行（伝票行 `999999999`）付き
- 各行の発注数量・仕入金額は仕様通りの計算式（発注数量 = 発注単位数 × ロット数 × 発注ロット数、仕入金額 = 発注数量 × 単価）で計算済みです。
