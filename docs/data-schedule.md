# データ作成スケジュール

[← 仕様書に戻る](../specification.md)

## 作成スケジュール

- CSVファイルは **毎朝6:00〜21:45** の間、**15分おき**に作成されます。
- 取引先様は、作成タイミングより **2〜3分ほど遅らせて** FTPよりダウンロードしてください（目安：毎時3分・18分・33分・48分）。

## 作成の仕組み（ワークフロー）

CSVは15分ごとに、以下の手順で **その都度ゼロから作り直されます**（前回分への追記ではありません）。

1. ディレクトリ内のCSVをすべて削除する
2. DBの発注日を検索し、当日分のデータを抽出する
3. 仕様に従いCSVファイルを生成する
4. 指定ディレクトリに設置する

この処理が、6:00〜21:45の間、15分おきに繰り返されます。

## 納品日の決まり方

- 発注日は、常に **データ送信日**（弊社が発注データを送信した日）になります。
- 納品日は、リードタイム（曜日ごとに設定された発注〜納品までの日数）をもとに自動計算されますが、弊社がリードタイムよりも先の日付を指定することもあります。

| 発注時の納品日指定 | 発注日 | 納品日 |
| --- | --- | --- |
| 指定しない | データ送信日 | データ送信日 + リードタイム |
| 指定する | データ送信日 | 指定した納品日 |

### 例：納品日を指定した発注が混在するケース

前提条件：
- FTP受信は毎日9:33に行う取り決め
- 1伝票あたり6行
- リードタイムは全曜日1日

| 時刻 | 弊社の操作 | 作成されるCSV |
| --- | --- | --- |
| 09:13 | 納品日指定なしで12アイテムを発注 | - |
| 09:15 | - | 伝票2枚・12アイテム（納品日は翌日） |
| 09:18 | 納品日を翌々日に指定して3アイテムを追加発注 | - |
| 09:30 | - | 伝票3枚・15アイテム |
| 09:33 | 取引先様がFTPよりダウンロード | 伝票3枚・15アイテム |
| 09:45 | - | 伝票3枚・15アイテム |
| … | … | … |
| 21:45 | - | 伝票3枚・15アイテム |

## 発注確定後に追加発注があった場合

- 追加された分には **新しい伝票番号** が付与されます（既存の伝票への行追加にはなりません）。
- 次回のCSV作成時には、**既存データと追加データの両方** が含まれて出力されます（既存データの伝票番号はそのまま維持されます）。
- そのため、取引先様側で追加分だけを取り込みたい場合は、既存データとの重複に対する対応が必要です。

### 例：発注確定を2回行ったケース

前提条件：
- FTP受信は毎日9:33に行う取り決め
- 1伝票あたり6行

| 時刻 | 弊社の操作 | 作成されるCSV |
| --- | --- | --- |
| 09:13 | 12アイテムを発注 | - |
| 09:15 | - | 伝票2枚・12アイテム |
| 09:18 | 3アイテムを追加発注 | - |
| 09:30 | - | 伝票3枚・15アイテム |
| 09:33 | 取引先様がFTPよりダウンロード | 伝票3枚・15アイテム |
| 09:45 | - | 伝票3枚・15アイテム |
| … | … | … |
| 21:45 | - | 伝票3枚・15アイテム |
