# FTPについて

[← 仕様書に戻る](../specification.md)

## アカウント

- 取引先様ごとに、専用のユーザー名・パスワードを発行します。
- 取引先様用アカウントは **読み取り専用** です（アップロードや削除はできません）。

## 接続モード

- 本サーバーは **パッシブモード（PASV）** に対応しています。
- ファイアウォールやNAT配下の環境からご利用の場合は、クライアント側の接続設定でパッシブモードを選択してください。

> 以下の情報については、メールにてお問い合わせください。
> - FTPサーバーアドレス
> - FTPユーザー名
> - FTPパスワード
> - FTPディレクトリ
