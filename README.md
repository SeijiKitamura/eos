# 株式会社スーパーキタムラ EOS仕様書

株式会社スーパーキタムラが取引先様と行う**EOS発注（電子データによる商品発注）**の仕様をまとめたリポジトリです。

## EOSとは

- EOSとは、弊社が取引先様に行う商品発注を電子データでやり取りする仕組みです。
- 発注データ（CSVファイル）を**FTP**を使用してやり取りします。
- やり取りするのは**発注データのみ**です（納品データ・請求データは非対応）。
- FTPのユーザー名・パスワードは取引先様ごとに発行されます。

> [!WARNING]
> CSVは弊社独自の仕様です。業界推奨の流通BMSには対応していません。

## 全体の流れ

1. 弊社が発注データを作成
2. CSVファイルがFTPサーバーに設置される
3. 取引先様がFTPサーバーにログインし、該当ファイルをダウンロード

## CSVについて

| 項目 | 値 |
| --- | --- |
| ファイル名 | 固定（`eXXXX.csv`、Xは4桁の数字） |
| 文字コード | UTF-8 |
| データ形式 | CSV（各列をカンマ区切り） |
| 列名 | なし |
| 並び順 | 伝票番号、伝票行で昇順 |
| 合計行 | 伝票行「999999999」 |

CSVは25列で構成され、仕入先コード・伝票番号・JANコード・商品名・単価・発注数量・店舗情報などを含みます。各列の詳細な定義（型・変更可否・備考）は [CSVファイル仕様](docs/csv-format.md) を参照してください。

## データ作成スケジュール

- **毎朝6時**から**21時45分**まで、**15分刻み**でCSVファイルを作成します。
- 作成の都度、ディレクトリ内の既存CSVを削除し、当日発注分のデータを再生成して設置します。
- ダウンロードは上記スケジュールより2〜3分ほど遅らせてのご対応を推奨しています（例：3分・18分・33分・48分）。

発注確定後に商品が追加された場合や納品日の指定など、データ作成の詳細な挙動は [データ作成スケジュール](docs/data-schedule.md) にまとめています。

## FTPについて

- 取引先様ごとにユーザー名・パスワードを発行します（**読み取り専用**アカウント）。

> [!NOTE]
> 以下の内容についてはメールにてお問合せください。
> - FTPサーバーアドレス
> - FTPユーザー名
> - FTPパスワード
> - FTPディレクトリ

## よくある質問（抜粋）

- ファイル名は固定で、`eXXXX.csv`（Xは4桁の数字）です。
- 発注がない日は空ファイルではなく、ディレクトリが空になります。
- 追加発注は既存の伝票番号への行追加ではなく、新しい伝票番号が付与されます。その際、既存データも含めてCSVが再作成されます。
- 表示されている単価・売価はすべて**税抜価格**です。
- テスト環境の準備も可能です（お申し出から1週間以内にご用意）。

その他の質問については [Q&A](docs/faq.md) をご確認ください。
